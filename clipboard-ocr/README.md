# clipboard-ocr

クリップボード上の画像(スクリーンショット)に含まれる日本語テキストをOCRでテキスト化し、クリップボードをそのテキストで上書きするWindows専用ツールです。スクリーンショットの取得自体は既存のツール(Win+Shift+Sなど)にお任せし、本ツールは「グローバルホットキー(Win+Shift+X) → OCR → クリップボード上書き」だけを担当します。

## 前提条件

- **Windows 10/11 + 日本語OCR言語パック**: 設定 > 時刻と言語 > 言語と地域 で日本語を追加し、その言語のオプション機能から「光学式文字認識」を追加してください(未インストールの場合、起動時にエラーで終了します)。
- **Windows PowerShell (`powershell.exe`) 必須**: PowerShell 7 (`pwsh.exe`) では動作しません(WinRTのOCR APIをPowerShell 7から読み込めないため)。
- **実行ポリシー**: 既定の実行ポリシーではローカルスクリプトの実行がブロックされます。下記のように `-ExecutionPolicy Bypass` を付けて実行してください(システム全体の設定は変更しません)。

## 使い方

```
# 現在のクリップボードの画像を1回だけOCRして終了(動作確認・単発利用に)
powershell.exe -ExecutionPolicy Bypass -File Watch-ClipboardOcr.ps1 -Once

# グローバルホットキー(Win+Shift+X)で待受(コンソールウィンドウ有り)
powershell.exe -ExecutionPolicy Bypass -File Watch-ClipboardOcr.ps1
```

上記はコンソールウィンドウを開いたままバックグラウンドで動作します。終了するにはそのコンソールウィンドウを閉じてください。

## Windowsログイン時の自動起動(ウィンドウ非表示)

コンソールウィンドウを出さずに、ログイン時に自動でリスナーを起動したい場合:

1. `Start-Hidden.vbs`(`clipboard-ocr` フォルダ内)が、`Watch-ClipboardOcr.ps1` をウィンドウ無しで起動するランチャーです。中身は `WScript.Shell.Run(..., 0, False)` でコンソールを一切表示せずにPowerShellを起動するだけの単純なスクリプトです。
2. スタートアップフォルダ(`Win+R` → `shell:startup`)に、`wscript.exe "<clipboard-ocrフォルダの絶対パス>\Start-Hidden.vbs"` を実行するショートカットを作成します。

以下はこのショートカットを自動作成するPowerShellコマンドです(パスは自分の環境に合わせて書き換えてください):

```powershell
$WshShell = New-Object -ComObject WScript.Shell
$Shortcut = $WshShell.CreateShortcut("$([Environment]::GetFolderPath('Startup'))\ClipboardOCR.lnk")
$Shortcut.TargetPath = "$env:WINDIR\System32\wscript.exe"
$Shortcut.Arguments = '"<clipboard-ocrフォルダの絶対パス>\Start-Hidden.vbs"'
$Shortcut.WorkingDirectory = '<clipboard-ocrフォルダの絶対パス>'
$Shortcut.Description = 'Clipboard OCR listener (Win+Shift+X)'
$Shortcut.Save()
```

**無効化・削除したいとき**: 設定 > アプリ > スタートアップ で「ClipboardOCR」をオフにするか、`shell:startup` を開いて `ClipboardOCR.lnk` を削除してください。

## 終了コード

| コード | 意味 |
|---|---|
| 0 | 成功。クリップボードが認識テキストに置き換わった |
| 1 | PowerShellのエディションが不正(`pwsh.exe`で実行した) |
| 2 | OCRエンジン利用不可(日本語OCR言語パック未インストール) |
| 3 | クリップボードに画像がない(空、またはテキスト等) |
| 4 | グローバルホットキーの登録に失敗(他のインスタンス/アプリと競合) |
| 5 | 画像はあるが認識テキストが空だった |
| 6 | 想定外のエラー |

コード1・2・4はプロセス全体が即終了する致命的エラーです。コード3・5は待受モード中はログに記録されるだけでリスナーは継続し、クリップボードも変更されません。

## トラブルシューティング

- **「日本語OCR言語パックが見つかりません」と出る**: 上記の前提条件を参照し、日本語の「光学式文字認識」機能を追加してください(追加後、再起動が必要な場合があります)。
- **「グローバルホットキーの登録に失敗しました」と出る**: 既にこのツールの別インスタンスが起動しているか、他のアプリがWin+Shift+Xを使っています。他のインスタンス/アプリを終了してから再実行してください。
- **スクリプトの実行がブロックされる**: `-ExecutionPolicy Bypass` を付け忘れていないか確認してください。
- **認識結果の改行が期待と違う**: Windows OCRは行単位でテキストを認識するため、元の段落の折り返しとは異なる改行になる場合があります。
- **認識結果に文字の誤り(誤字)がある**: 実際のスクリーンショット(特にダークテーマ・小さいフォント)では、Windows OCRエンジン自体が「です」を「てす」と読み違える、「ー」(長音記号)を「-」(ハイフン)と読み違えるなど、数%程度の誤認識が起こり得ます。これは本ツールの不具合ではなくOCRエンジンの精度限界です。重要な文章は目視確認してください。
- **小さいバッジ・アイコン付きラベルなどの画像で認識できない**: 短辺200px未満の画像は自動的に2倍に拡大してからOCRに渡すようにしています(小さい画像はWindows OCRが文字を全く拾えない、または「ー」を「-」と読み違えることがあるため)。それでも認識できない場合は、範囲を少し広めにスクリーンショットし直してみてください。
- **CTRL/SHIFT/ALTなどのキー名が文字化けする**: 「SHIFT」が「s印FT」のように一部だけ別の文字に化けることが実測で確認されています。既知のキー名(CTRL/SHIFT/ALT/WIN/TAB/ESC/ENTER/F1〜F12等)については、あいまい一致で正しいキー名に自動補正するようにしています。ただし文字が丸ごと数文字消えてしまうほど激しく壊れた場合は補正しきれないことがあります。
- **日本語の文の最後の「!」「?」が半角になる**: Windows OCRは全角の「！」「？」を半角として認識することがあります。直前の文字が日本語(ひらがな・カタカナ・漢字)の場合は自動的に全角へ変換します(英単語の直後など、日本語の文脈でない場合は半角のままです)。
- **自動起動(`Start-Hidden.vbs`経由)したはずのリスナーが動いていない**: Windows 11には初めて登録されたスタートアップ項目の起動を数分遅らせる仕組みがあるため、ログイン直後は起動していないことがあります。少し待ってから確認してください。それでも起動していない場合は、致命的エラー(終了コード1・2・4)は必ずログファイルに記録されるため、`%LOCALAPPDATA%\clipboard-ocr\clipboard-ocr.log` を確認してください。

## 既知の制限

- 手動で `powershell.exe -File Watch-ClipboardOcr.ps1` を実行した場合はコンソールウィンドウが表示されたままです。ウィンドウを出したくない場合は上記の自動起動(`Start-Hidden.vbs`経由)を使ってください。
- 完了時の通知(トースト・音)は出しません。クリップボードの中身が変わったことで判断してください。
- ログは `%LOCALAPPDATA%\clipboard-ocr\clipboard-ocr.log` に出力されます。成功時は何も記録されませんが、致命的エラー(終了コード1・2・4、自動起動時にコンソールが非表示でも)は必ず記録されます。
- **リスナー稼働中はWin+Shift+Xがシステム全体で本ツールに割り当てられます**。他のアプリがそのショートカットを使っていても、稼働中は本ツールが優先され、元のアプリには届きません。
- OCR言語は日本語のみを想定しているため、認識結果の行内は単語をスペース無しで連結しています。英単語がスペース区切りで含まれる画像(例: "Hello World")では、そのスペースも失われます("HelloWorld"になる)。
