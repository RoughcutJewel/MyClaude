# 自由の女神(Statue of Liberty) 出題対策ノート

決勝地ニューヨークの象徴であり、旧番組でも○×クイズの定番出題対象(第2回で「たいまつを持っているのは左手である」が出題され×、等)だったため優先的に研究。

**出典**: [米国国立公園局(NPS)公式ページ](https://www.nps.gov/stli/learn/statue-of-liberty-facts.htm)(政府機関の公式情報、一次情報に近い) / [自由の女神像 - Wikipedia](https://ja.wikipedia.org/wiki/自由の女神像_(ニューヨーク))(二次資料)。2ソースを突き合わせ、数値の一致・不一致を明記。

## 基礎データ(2ソース一致、確度高)

| 項目 | 内容 |
|---|---|
| 正式名称 | "Liberty Enlightening the World"(世界を照らす自由) |
| 除幕式 | 1886年10月28日(グロバー・クリーブランド大統領出席) |
| 建設期間 | フランスで1875〜1884年制作、1885年に船で輸送、1886年組立完了 |
| 像の高さ(台座上〜たいまつ先端) | 151フィート1インチ(46.05m) |
| 台座の高さ | 約153〜154フィート(46.9〜47m、資料により微差) |
| 総高(地面〜たいまつ先端) | 305フィート1インチ(約93m) |
| 素材 | 銅(外装)。酸化により緑色に変色(元は銅色) |
| 彫刻設計者 | フレデリック=オーギュスト・バルトルディ |
| 構造設計者 | ギュスターヴ・エッフェル(エッフェル塔の設計者と同一人物)、ヴィオレ・ル・デュク |
| 台座設計者 | リチャード・モリス・ハント |
| 台座資金 | ジョーゼフ・ピューリッツァー(「ニューヨーク・ワールド」紙社主)が新聞キャンペーンで一般市民から寄付を募った |
| 設置場所 | リバティ島(旧称ベドロー島、1956年に改称) |
| 贈呈国 | フランスからアメリカへの贈り物。独立100周年(1876年)を記念する構想だったが、実際の除幕は1886年で10年遅れた |

## ○×のひっかけになりやすい象徴要素(最重要・出題頻出想定)

| 部位 | 内容 | ひっかけの型 |
|---|---|---|
| たいまつ | **右手**に掲げている | 「左手」への言い換え(過去に実際出題された定番パターン) |
| 銘板(タブレット) | **左手**に持つ。"JULY IV MDCCLXXVI"(1776年7月4日、独立宣言の日)がローマ数字で刻まれている | アラビア数字への言い換え/「建国記念日」等の別名称への言い換え |
| 王冠のとげ | **7本**。7つの大陸・7つの海を象徴 | 本数(7)の数字トラップ、意味の取り違え(大陸と海の両方を象徴する点を見落としやすい) |
| 足元 | 引きちぎられた鎖と足かせ | 「踏みつけている」等の描写の誇張・改変 |

## 未解決の不一致(要追加裏取り)

**重量**: NPS公式は「像本体 約254,000kg(560,000ポンド)」、日本語版Wikipediaは「総重量225トン」と記載しており数値が一致しない。単位の取り方(像のみ/台座含む)の違いの可能性があるが未解消。**出題する場合は重量関連の設問は避けるか、さらに裏取りしてから使うこと。**

## 出題設計への応用(question-design-tendencies.mdのパターンと対応)

- パターン1(定番トリビア型)の典型例そのもの。「自由の女神」自体は誰もが知っているが、利き手・王冠の本数・持ち物の左右は正確に覚えている人が少ない
- パターン3(穴埋め型の虚偽混入)にも使える: 「銘板には独立記念日の日付がアラビア数字で刻まれている」のような、事実文の1点だけを変える形式

## 出題の切り口分析

| 観点 | 該当する問題 | 特徴 |
|---|---|---|
| 身体的特徴・持ち物 | たいまつの左右、銘板の内容 | 「知ってるつもり」型の王道。最頻出パターンと推定 |
| 方角・位置関係 | 西郷隆盛像との比較、フランスの方角 | 単体の知識でなく「他の何かとの関係性」を問う、一段高度な形式。国内の対象物と絡めることで番組を熱心に見た層への訴求を狙う |
| 建造・除幕の経緯 | 除幕式の幕の色柄、建造時の高さ比較 | 年号暗記でなく儀式のディテールを問う意外性重視型 |
| 法的地位・行政上の扱い | 灯台としての公式地位、損害保険、名誉市民の称号 | 観光地としての一般的イメージと行政上の実態のギャップを突く高度なパターン |
| 言語・翻訳史 | 「自由の女神」という訳語の成立時期 | 対象物自体でなく日本語での呼称の歴史という、一段メタな切り口 |
| 国際交流・返礼 | フランスへの返礼像の有無 | 対象物を超えた外交・友好関係の文脈知識 |

**総括**: 「対象物そのものの物理的特徴」だけでなく、「法的地位・行政上の扱い」「言語・翻訳史」「国際交流」といった、観光地としての表層イメージを超えた文脈知識に踏み込む出題傾向がある。物理的特徴(高さ・素材・利き手)の暗記だけでは不十分で、自由の女神が米国政治・行政・外交の中でどう位置づけられてきたかという周辺知識まで押さえる対策が有効と考えられる。

## 訳語「自由の女神」の成立史(2026-07-20裏取り)

明治19年(1886年、像の除幕と同年)の郵便報知新聞が最初に「女神」と訳した記録が残る(フランス語のliberté=自由が女性名詞であることに由来)。その後「自由の神像」(1910年)「自由女神像」(1916年)等の表記ゆれを経て、**1920年代〜1930年頃(特に1924年頃の大阪朝日新聞あたり)に「自由の女神」という表記が定着**した。したがって「訳したのは戦後」という言説は史実として誤りの可能性が高い。出典: [Yahoo!知恵袋の回答](https://detail.chiebukuro.yahoo.co.jp/qa/question_detail/q10206763070)(引用元の当時の資料名は明記されているが、この回答自体は単一ソースであり追加裏取りが望ましい)。

## 「日本語で・日本人向けに作る」という制約からの分析

自由の女神問題(特に西郷隆盛像との比較・訳語の成立史)は、[question-design-tendencies.md](../question-design-tendencies.md)で追加した「二重翻訳型」パターンの典型例。海外の対象を単体で問うのではなく、(a) 日本の既知の対象と比較する「架橋」技法、(b) 対象そのものでなく日本語による受容史を問う「言語ネタ」、(c) 「意外性」の基準を日本人の平均的予備知識との落差で設定する、(d) 日本の学校教育のカリキュラム内に収まる周辺知識を選ぶ、という4技法によって「アメリカについての問題」が実質的に「アメリカを通して日本を映す問題」に変換されている。詳細は[question-design-tendencies.md](../question-design-tendencies.md)を参照。
