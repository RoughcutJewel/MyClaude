# 自由の女神(Statue of Liberty) 出題対策ノート

決勝地ニューヨークの象徴であり、旧番組でも○×クイズの定番出題対象(第2回で「たいまつを持っているのは左手である」が出題され×、等)だったため優先的に研究。

**出典**: [米国国立公園局(NPS)公式ページ](https://www.nps.gov/stli/learn/statue-of-liberty-facts.htm)(政府機関の公式情報、一次情報に近い) / [自由の女神像 - Wikipedia](https://ja.wikipedia.org/wiki/自由の女神像_(ニューヨーク))(二次資料)。2ソースを突き合わせ、数値の一致・不一致を明記。

## 基礎データ(2ソース一致、確度高)

| 項目 | 内容 |
|---|---|
| 正式名称 | "Liberty Enlightening the World"(世界を照らす自由) |
| 除幕式 | 1886年10月28日(グロバー・クリーブランド大統領出席) |
| 建設期間 | フランスで1875〜1884年制作、1885年に船で輸送、1886年組立完了 |
| 像の高さ(台座上〜たいまつ先端) | 151フィート1インチ(46.05m) |
| 台座の高さ | 約153〜154フィート(46.9〜47m、資料により微差) |
| 総高(地面〜たいまつ先端) | 305フィート1インチ(約93m) |
| 素材 | 銅(外装)。酸化により緑色に変色(元は銅色) |
| 彫刻設計者 | フレデリック=オーギュスト・バルトルディ |
| 構造設計者 | ギュスターヴ・エッフェル(エッフェル塔の設計者と同一人物)、ヴィオレ・ル・デュク |
| 台座設計者 | リチャード・モリス・ハント |
| 台座資金 | ジョーゼフ・ピューリッツァー(「ニューヨーク・ワールド」紙社主)が新聞キャンペーンで一般市民から寄付を募った |
| 設置場所 | リバティ島(旧称ベドロー島、1956年に改称) |
| 贈呈国 | フランスからアメリカへの贈り物。独立100周年(1876年)を記念する構想だったが、実際の除幕は1886年で10年遅れた |

## ○×のひっかけになりやすい象徴要素(最重要・出題頻出想定)

| 部位 | 内容 | ひっかけの型 |
|---|---|---|
| たいまつ | **右手**に掲げている | 「左手」への言い換え(過去に実際出題された定番パターン) |
| 銘板(タブレット) | **左手**に持つ。"JULY IV MDCCLXXVI"(1776年7月4日、独立宣言の日)がローマ数字で刻まれている | アラビア数字への言い換え/「建国記念日」等の別名称への言い換え |
| 王冠のとげ | **7本**。7つの大陸・7つの海を象徴 | 本数(7)の数字トラップ、意味の取り違え(大陸と海の両方を象徴する点を見落としやすい) |
| 足元 | 引きちぎられた鎖と足かせ | 「踏みつけている」等の描写の誇張・改変 |

## 未解決の不一致(要追加裏取り)

**重量**: NPS公式は「像本体 約254,000kg(560,000ポンド)」、日本語版Wikipediaは「総重量225トン」と記載しており数値が一致しない。単位の取り方(像のみ/台座含む)の違いの可能性があるが未解消。**出題する場合は重量関連の設問は避けるか、さらに裏取りしてから使うこと。**

## 出題設計への応用(question-design-tendencies.mdのパターンと対応)

- パターン1(定番トリビア型)の典型例そのもの。「自由の女神」自体は誰もが知っているが、利き手・王冠の本数・持ち物の左右は正確に覚えている人が少ない
- パターン3(穴埋め型の虚偽混入)にも使える: 「銘板には独立記念日の日付がアラビア数字で刻まれている」のような、事実文の1点だけを変える形式
